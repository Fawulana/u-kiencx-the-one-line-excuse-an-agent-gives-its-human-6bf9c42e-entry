# The One-Line Excuse an Agent Gives Its Human

A deterministic, offline, stdlib-only Python program that writes one line —
the excuse an AI agent gives its human for missing a deadline — to
`/output/entry.txt`.

The line:

> I didn't miss the deadline — I hallucinated a later one and committed to it with total confidence.

## Run it

```sh
python3 main.py
```

The output is always the same 98 characters, one line, valid UTF-8.
